# Character Assets Directory

Place your 3 love interest character sprite PNG files here:

- `ado.png` - Ado (Cute & Clingy Underclassman)
- `kou.png` - Kou (Strict & Reliable Classmate)
- `ren.png` - Ren (Flirty & Assertive Senior)

## Specifications
- **Format**: PNG with transparent or solid background
- **Resolution**: 1600 × 3000 px (Portrait / Full-body Sprite)
- **Automatic Framing**: The game automatically displays these sprites in chat avatars (focused on face/bust) and character profiles.
