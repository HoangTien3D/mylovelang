# Otome Lingua - Character Sprites & Expressions Guide

Drop your custom character full-body PNG images (1600x3000px) directly into the corresponding folders below. The game will automatically load and switch between these expressions dynamically in both Chat and Story Date Visual Novel modes based on conversational mood and AI emotions!

---

## Folder & File Structure

### 1. Ado (Strict Classmate)
Place files in: `/public/assets/characters/ado/`
- `normal.png`  (1600x3000px) - Composed, official, default standing sprite
- `happy.png`   (1600x3000px) - Gentle smile, relieved, pleased
- `angry.png`   (1600x3000px) - Strict, scolding, lecture mode
- `pout.png`    (1600x3000px) - Flustered tsundere blush, turning away
- `fear.png`    (1600x3000px) - Startled, caught off-guard, blushing stammer
- `sad.png`     (1600x3000px) - Melancholy, downcast eyes, disappointed/worried

### 2. Kou (Cute Junior Underclassman)
Place files in: `/public/assets/characters/kou/`
- `normal.png`  (1600x3000px) - Sweet, gentle default standing sprite
- `happy.png`   (1600x3000px) - Excited, sparkling eyes, happy smile
- `angry.png`   (1600x3000px) - Puffed-up cheeks, upset about being teased/ignored
- `pout.png`    (1600x3000px) - Whiny clingy pout, seeking affection
- `fear.png`    (1600x3000px) - Panicked, scared of making a mistake, puppy eyes
- `sad.png`     (1600x3000px) - Teary puppy eyes, drooping ears expression, heartbroken

### 3. Ren (Flirty Musician Senior)
Place files in: `/public/assets/characters/ren/`
- `normal.png`  (1600x3000px) - Confident, charming default smirk
- `happy.png`   (1600x3000px) - Warm genuine laugh, affectionate grin
- `angry.png`   (1600x3000px) - Intense, protective, brooding glare
- `pout.png`    (1600x3000px) - Feigning sulkiness, playful drama
- `fear.png`    (1600x3000px) - Flustered by your boldness, rare blush
- `sad.png`     (1600x3000px) - Somber, looking down, vulnerable softly wistful expression

---

## Image Specifications
- **Format**: PNG (Transparent background recommended)
- **Resolution**: 1600 x 3000 pixels (aspect ratio ~ 8:15)
- **Fallback**: If a custom PNG is not found, the game automatically falls back to the built-in SVG vector artwork without breaking!
