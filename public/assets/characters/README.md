# Love Interest Character Assets

Place your custom character art files directly in this folder (`/public/assets/characters/`):

### 1. Avatars (Square / 256 × 256 px)
- `ado_avatar.png` — Ado (Cute Underclassman)
- `kou_avatar.png` — Kou (Strict Classmate)
- `ren_avatar.png` — Ren (Flirty Senior)

### 2. Floating Fullbody Standees (Portrait / 1600 × 3000 px)
- `ado_fullbody.png` (or `Ado.png`) — Ado Standing Sprite
- `kou_fullbody.png` (or `Kou.png`) — Kou Standing Sprite
- `ren_fullbody.png` (or `Ren.png`) — Ren Standing Sprite

---
The app will automatically detect and display these files across chatrooms, chat headers, message bubbles, and floating companion stages!
