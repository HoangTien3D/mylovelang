# Scenario Background Images (512x512 JPEG)

This folder contains the local background images for the Visual Novel Date Scenarios.

## Adding or Replacing Images Locally:
You can drop in or replace your own **512x512 JPEG** images in this directory using any of these filenames:

1. **Scenario 1 (Library Study Date)**:
   - `scenario_1.jpg` (or `library.jpg`)
2. **Scenario 2 (Rainy Cafe & Warm Drinks)**:
   - `scenario_2.jpg` (or `cafe.jpg`)
3. **Scenario 3 (Sunset Riverbank Walk)**:
   - `scenario_3.jpg` (or `riverbank.jpg`)
4. **Scenario 4 (Night Festival & Fireworks)**:
   - `scenario_4.jpg` (or `festival.jpg`)
5. **Scenario 5 (Rooftop Stargazing & Confession)**:
   - `scenario_5.jpg` (or `rooftop.jpg`)

## Requirements:
- **Format**: JPEG / JPG (`.jpg` or `.jpeg`)
- **Dimensions**: 512 × 512 pixels (1:1 square aspect ratio)
- **Display**: Automatically styled with `background-size: cover; background-position: center;` to fill the entire square card without distortion.
